# Tiku Prompt v0.1.0

首个公开版本。

## 功能

- 离线生成 AI 出题提示词，不调用模型、不需要 API Key、不联网。
- 共享出题范围：年级、学期、学科、教材、单元/课时、题量、难度、输出语言、额外要求、补充资料。
- 三种导入格式：
  - StudyOnTV / 题了个题：v2，支持单选、多选、判断、填空、主观。
  - PlanYourTV：v1，支持单选、多选。
  - 学习锁：v2.5+，四选一单选题。
- 内置 410 本教材、2870 个单元和 8973 条非空课时标题，只有目录标题，不含教材正文、题目或答案。
- 复制提示词、系统分享、导入格式说明和表单设置保存均在本地完成。

## 安装

- Android 7.0（API 24）及以上。
- 下载本 Release 中的 APK，按系统提示允许安装未知来源应用。
- 如需校验，下载同页的 `SHA256SUMS`，在文件所在目录运行：

  ```bash
  sha256sum -c SHA256SUMS
  ```

- `release-info.txt` 记录了版本、提交、签名证书指纹和 APK 权限。

## 兼容性与数据

- 本项目是独立工具，与 StudyOnTV、PlanYourTV、学习锁的开发者无关联；格式兼容均为非官方，目标 App 的更新可能改变导入行为。
- 目录数据来自 PlanYourTV 的教材目录资产（MIT），标题整理自国家中小学智慧教育平台公开的课程目录。
- 不包含 StudyOnTV 源码或资产，不包含学习锁代码、资源或题库。
- 应用没有 `INTERNET` 权限。AI 输出请自行核对，尤其是多选题、填空题和解析。

# 题库提示词（Tiku Prompt）

安卓端的离线 AI 出题提示词生成器。选择目标 App 的 JSON 格式和出题范围后，在本机拼好提示词，复制或分享到任意 AI 对话；模型返回 JSON 后，再导入目标 App。

应用本身**不调用模型、不需要 API Key、不联网**，`AndroidManifest.xml` 中没有 `INTERNET` 权限。提示词和表单设置只在本机处理。

> 本项目提供非官方的导入格式兼容；目标 App 更新后，导入行为可能变化。

## 支持的目标格式

| 目标 | 导入格式 | 题型 |
| --- | --- | --- |
| StudyOnTV / 题了个题 | v2 `{version: 2, items}` | 单选、多选、判断、填空、主观 |
| PlanYourTV | v1 `{version, items}` | 单选、多选 |
| 学习锁 | v2.5+ `{items}`，每题 `s/o/a/e` | 四选一单选题（固定 4 个选项） |
| HaloTV | 3.6+ `halotv-parent-quiz-v1` | 2–4 选一单选题 |

HaloTV 每局抽 5 题；自定义题库不足 5 题时，会用内置题库补齐。

出题范围（年级、学期、学科、教材、单元/课时、题量、难度、输出语言）由所有格式共享；切换目标只替换提示词末尾的 JSON 格式规范，已选范围会保留。

## 局域网家长端

选择目标 App 后，在“局域网家长端”中粘贴电视上显示的完整地址并保存。地址按目标分别保存，只存在本机；点击“打开家长端”会交给系统浏览器。应用不会自动扫描局域网、不探测地址，也没有网络权限。

- StudyOnTV：通常为 `http://电视IP:8099/`，打开后按电视端设置输入家长密码。
- 学习锁：使用电视显示的完整地址，通常为 `http://电视IP:8765/?t=8位验证码`；验证码会更新，失效后重新复制并修改保存。
- PlanYourTV / HaloTV：使用电视“家长中心”或“手机管理中心”显示的完整地址/二维码内容；端口和配对信息以电视显示为准，本项目不写死端口。
- 地址里可能包含临时验证码或配对码；只保存在本机应用数据中，不随提示词导出或分享。

## 使用

1. 选择目标 App、教材和出题范围。
2. 按需设置题型、题量、难度、选项数、输出语言；如需补充教材原文或额外约束，生成后直接在提示词里修改（内置课程目录只有教材、单元和课时标题，没有课文正文）。
3. 复制提示词，粘贴到任意 AI 对话。
4. 把 AI 返回的 JSON 导入目标 App，并人工核对题目、答案和解析。
5. 学习锁支持在应用内直接打包：复制提示词后，把 AI 返回的 JSON 粘贴到“AI 结果 → 学习锁 zip”；可连续添加多个题库（不同学科或不同提示词的结果），一次生成一个包含多个题库的 zip。JSON 只在本机校验，zip 通过系统文件选择器保存。
6. 学习锁也可以手动制作 zip：把单个 JSON 保存为 UTF-8 无 BOM 的 `.json`，直接压缩到 zip 根目录，不要套文件夹；应用生成的 zip 会自动附带 `index.json` 和每个题库的 JSON。
7. HaloTV 也支持在应用内校验和导出：把 AI 返回的 JSON 粘贴到“AI 结果 → HaloTV 题库”（或选择文件），应用会按 HaloTV 3.6+ 的 `halotv-parent-quiz-v1` 规则检查题库名、题干、选项和答案，通过后导出 `.json`。再到手机管理页的“儿童与长辈 → 家长出题 → 导入题库”选择该文件；每次导入会新建题库，单题库最多 80 题，全部题库合计最多 80 题。

## 数据与隐私

- 课程目录包含 410 本教材、2870 个单元和 8973 条非空课时标题，不含教材正文、图片、题目或答案。
- 目录数据取自 PlanYourTV 的教材目录资产（MIT），其标题整理自国家中小学智慧教育平台公开的课程目录。
- 目标 App 的格式规范用于描述导入 JSON 的形状和校验规则。
- StudyOnTV 的格式规范依据公开文档整理；其自身许可证为 Source Available / 个人使用。
- 学习锁是免费但闭源的第三方软件；本项目只描述其公开可见的导入格式。
- HaloTV 是第三方开源应用；本项目只描述其公开的家长出题 JSON 格式，不复制其源码、资源或题库，兼容性为非官方。
- 应用不收集、不上传任何数据，也没有网络权限。剪贴板、系统分享和局域网家长端地址由用户主动触发。
- 局域网家长端地址（可能包含临时验证码）只保存在本机应用数据中，不随提示词导出；打开时由系统浏览器访问网络。
- AI 输出的准确性由模型和使用者负责；导入前请核对，尤其是多选题、填空题和解析内容。

更完整的数据来源与第三方许可证说明见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) 和 [NOTICE](NOTICE)。

## 构建与测试

本地构建要求：

- JDK 17
- Android SDK Platform 36
- Android Build-Tools 35.0.0
- Gradle Wrapper（仓库已包含）

```bash
./gradlew :app:testDebugUnitTest
./gradlew :app:assembleDebug
```

单元测试是纯 JVM 测试，会校验课程数据、目标顺序、格式切换、提示词拼接、局域网地址规范化、学习锁 zip 打包、HaloTV JSON 校验/导出和错误处理。生成的 debug APK 位于 `app/build/outputs/apk/debug/`。

## 代码结构

```text
app/src/main/
  assets/quiz/          年级、学科、教材、单元与课时目录（只读数据）
  assets/prompts/       各目标格式的格式规范
  java/.../model/       表单与领域模型
  java/.../data/        资产解析、课程目录、表单与地址持久化
  java/.../lan/         局域网家长端地址规范化
  java/.../prompt/      目标 Profile 元数据、表单校正、提示词拼接
  java/.../ui/          Compose 界面与 ViewModel
app/src/test/           纯 JVM 单元测试
```

添加新的答题 App 格式时，通常只需要：

1. 在 `app/src/main/assets/prompts/` 增加格式规范，末尾保留“出题要求：”标题；
2. 在 `TargetProfiles.kt` 注册格式元数据、支持的题型和数量/选项边界；
3. 补充对应测试，确认切换目标时共享范围不会丢失。
